# Cerebro · Cerebro de Contenido

Ideas que no se repiten, pedidos de grabación por WhatsApp, calendario y métricas para TikTok, Instagram y Facebook. Una cuenta maneja una o varias empresas.

## Instalar
1. Supabase → SQL Editor → pega `supabase/instalar-corto.sql` → Run (una sola vez; después se actualiza sola).
2. Crea tu cuenta con el correo del administrador y entra.
3. Cloudflare: conecta este repositorio (rama `main`).
